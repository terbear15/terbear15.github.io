# terbear15.github.io

Portfolio of **Terry Boxuan Xu**: urban spatial analytics (transportation, planning, data) and architecture.

Live: https://terbear15.github.io

## Structure

- `index.html`: home page (spatial analytics, architecture, about, contact)
- `projects/`: case-study pages (parking, heatscape, medilink)
- `assets/css/site.css`: all styles; colors and fonts in `:root`
- `assets/js/site.js`: scroll reveal, count-up stats, gallery lightbox
- `assets/img/`: compressed images (keep each under ~400 KB)

Architecture and map galleries are defined in the `window.GALLERY` object at the bottom of `index.html`.
Plain HTML/CSS/JS, no build step.
