# terbear15.github.io

Portfolio of **Terry Boxuan Xu**: urban spatial analytics and architecture. Live at https://terbear15.github.io

Plain HTML/CSS/JS, no build step needed to serve.

- `index.html` home · `spatial.html` spatial work · `architecture.html` flipbook portfolio · `tools.html` skills matrix · `resume.html`
- `projects/` case studies (parking, heatscape)
- `assets/css/main.css` design system (dark metallic, Helvetica)
- `assets/js/main.js` interactions (wheel, filters, flipbook, zoom, lightbox) · `assets/js/bg.js` contour + city-plan background
- `assets/arch/<project>/NN.webp` spreads (`-s` small, `-z` zoom) · `assets/img2/` images · `assets/media/` previews · `assets/data/` background data
